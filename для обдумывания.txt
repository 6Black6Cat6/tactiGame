1. Силуэтный контур (Outline Шейдер) — Самый популярный вариант
Шейдер автоматически находит края вашей картинки и дорисовывает вокруг неё светящуюся линию любого цвета, не трогая сам спрайт.
Как сделать:
Выберите ваш Sprite2D.
В инспекторе найдите CanvasItem -> Material и выберите New ShaderMaterial.
Нажмите на созданный материал, затем в поле Shader выберите New Shader.
Вставьте туда этот популярный 2D-код контура:
glsl
shader_type canvas_item;

uniform vec4 line_color : source_color = vec4(1.0, 1.0, 1.0, 1.0);
uniform float line_thickness : hint_range(0, 10) = 1.0;

void fragment() {
	vec2 size = TEXTURE_PIXEL_SIZE * line_thickness;
	float outline = 0.0;

	outline += texture(TEXTURE, UV + vec2(-size.x, 0.0)).a;
	outline += texture(TEXTURE, UV + vec2(size.x, 0.0)).a;
	outline += texture(TEXTURE, UV + vec2(0.0, -size.y)).a;
	outline += texture(TEXTURE, UV + vec2(0.0, size.y)).a;
	outline = min(outline, 1.0);

	vec4 color = texture(TEXTURE, UV);
	COLOR = mix(color, line_color, outline - color.a);
}
Используйте код с осторожностью.
В коде юнита вы можете включать и выключать этот контур, меняя толщину линии (line_thickness):
gdscript
func set_selected(is_selected: bool) -> void:
	var mat = $Sprite2D.material as ShaderMaterial
	if is_selected:
		mat.set_shader_parameter("line_thickness", 2.0) # Включаем контур
	else:
		mat.set_shader_parameter("line_thickness", 0.0) # Выключаем
Используйте код с осторожностью.
