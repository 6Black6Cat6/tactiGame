# Структура механик: 2D-стратегия (пошаговый реалтайм с полупрямым управлением)

---

## 1. БАЗОВЫЕ ПОНЯТИЯ

### 1.1. Ход
| Элемент | Описание |
|---------|----------|
| Фиксированный временной интервал | Каждый ход имеет заданную длительность (например, 3 секунды игрового времени) |
| Фаза планирования | Все игроки (включая ИИ-игроков) одновременно дают рекомендации/указания своим юнитам |
| Фаза симуляции | Система выполняет все действия в соответствии с рекомендациями и правилами |
| Автоматическая пауза | После завершения симуляции ход останавливается для следующего раунда планирования (возможно необязательна) |
| Возможность прерывания | Игрок не может управлять юнитами в середине хода при изменении обстановки |

### 1.2. Планирование: Рекомендация vs Указание
| Тип | Условие выполнения |
|-----|--------------------|
| Приказ | Действие запланированное игроком для юнита, которое будет выполнено обязательно - обычное прямое управление |
| Рекомендация | Действие запланированное игроком для юнита, которое выполняется только при соблюдении некоторых условий (например, вероятность успеха > порога) |
| Условия/Пороговые значения | Задаются глобально, индивидуально для юнита или для каждой рекомендации? |

Приказ может быть описан как рекомендация без условий.

## 2. ЮНИТ

### 2.1. Состав
| Компонент | Вложенные характеристики |
|-----------|--------------------------|
| Тело | Скорость, поворотливость, здоровье/прочность, текущее состояние, размер/габариты |
| Оружие | Конус разброса, дальность, урон, тип урона, боезапас, время перезарядки |

### 2.2. Сенсорика
| Элемент | Описание |
|---------|----------|
| Конус видимости | Угол обзора, максимальная дальность |
| Обнаружение | Условия (прямая видимость, укрытия, маскировка, шум) ??? |
| Память | Запоминает ли позиции скрывшихся врагов? На сколько ходов? |

### 2.3. Состояния
| Категория | Примеры |
|-----------|---------|
| Боевые | Здоровье, щиты, броня |
| Временные эффекты | Огонь, замедление, оглушение, отравление |
| Психологические | Мораль, паника (влияют ли на выполнение рекомендаций?) |
| Физические | Усталость, ранения (влияют на скорость, точность) |

## 3. ДЕЙСТВИЯ ЮНИТА

### 3.1. Перемещение
| Элемент | Описание |
|---------|----------|
| Влияющие факторы | Состояние юнита, тип местности, препятствия |
| Препятствия | Может ли блокировать движение? Тратит ли дополнительное время на обход? |

### 3.2. Атака
| Этап | Описание |
|------|----------|
| Выбор цели | Автоматический (приоритеты) / ручной (рекомендация игрока) |
| Расчёт выстрела | Базовая точность, конус разброса, дистанция, укрытие цели, состояние стрелка |
| Результат | Попадание (с указанием зоны), промах, критическое попадание |
| Расход ресурсов | Уменьшение боезапаса, необходимость перезарядки |
| Выстрел и движение | Стрельба в движении снижает точность, также как стрельба по движущейся цели |

## 4. ПРЕДНАСТРОЙКИ ИИ

### 4.1. Базовые типы
| Тип | Поведение |
|-----|-----------|
| Преследование | При виде врага пытается сократить дистанцию до оптимальной дальности выстрела |
| Оборона | Удерживает позицию, атакует приближающихся противников |
| Прокрасться | Перемещается, избегая обнаружения (минимизирует видимость/шум) |
| Настраиваемый | Игрок задаёт условия (например, «атаковать только если здоровье > 50%») |

### 4.2. Приоритет рекомендаций
| Вариант | Описание |
|---------|----------|
| Рекомендации важнее | Игровая рекомендация переопределяет преднастройку ИИ |
| Преднастройка важнее | Юнит следует ИИ, если рекомендация противоречит |
| Смешанный | Возможно ли комбинирование (например, «преследовать, но не приближаться к точке X»)? |

## 5. ВНЕШНЯЯ СРЕДА

### 5.1. Карта и местность
| Элемент | Влияние |
|---------|---------|
| Тип карты | непрерывная (не клеточная) |
| Типы местности | Скорость движения, укрытия, видимость |
| Препятствия | Блокируют движение, видимость, линию огня |
| Высота / рельеф | Бонус к обзору, точности, укрытию |
| Разрушаемость | Можно ли уничтожать укрытия и препятствия? |

### 5.2. Укрытия
| Аспект | Описание |
|---------|----------|
| Типы | Естественные (скалы, деревья), искусственные (стены, баррикады) |
| Механика | Снижают вероятность попадания, могут блокировать полностью |
| Использование | Может ли юнит активно занять укрытие (действие) или оно пассивно? |

## 6. ИНФОРМАЦИЯ И РАЗВЕДКА

### 6.1. Видимость
| Элемент | Описание |
|---------|----------|
| Прямая видимость | Линия без препятствий в пределах конуса |
| Косвенная | Шум, следы, датчики — дают ли частичную информацию? |
| Скрытность | Влияние маскировки, неподвижности, типа местности |

### 6.2. Обмен информацией между союзниками
| Элемент |  |
|---------|----------|
| Обмен | Все видят всё, что видят союзники? |
| Радиус связи | Есть ли ограничение по расстоянию обмена данными? |
| Задержка | Есть ли задержка при обмене данными между юнитами? Есть ли задержка при получении данных игроком (тогда важно его положение)? |

## 7. UI / UX (для игрока)

### 7.1. Визуализация планирования
Линиями от юнита до точки финиша - перемещение.

В нижней части экрана timeline с обозначением действий. При перемещении бегунка юниты перемещаются на соответствующие места. Если на поле есть объекты с равномерным движением - они также перемещаются. Местополложение же юнитов противника неопределено.

### 7.2. Прогноз вероятности
На фазе планирования также показывается вероятность попадения для текущего юнита с выбранным оружием.

### 7.3. Групповые действия
Приказы/рекомендации могут быть выданы сразу группе юнитов.

### 7.4. Обратная связь
| Элемент | (Пробел) |
|---------|----------|
| История хода | Просмотр того, что произошло за предыдущий ход |
| Логи боёв | Детальные расчёты (почему попал/промахнулся) |
