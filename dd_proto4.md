# Прототип: пошаговая стратегия с рекомендациями (Godot)

## 1. ОПИСАНИЕ МЕХАНИКИ (ЯДРО)

### 1.1. Ход
| Элемент               | Описание                                                     |
|-----------------------|--------------------------------------------------------------|
| Ручное переключение   | Игрок(и) вручную запускает фазу симуляции после планирования |
| Фаза планирования     | Игрок(и) дают приказы своим юнитам                           |
| Фаза симуляции        | Система выполняет расчет приказов и физики                   |
| Отсутствие прерываний | Во время симуляции управление невозможно                     |

### 1.2. Планирование
Приказы разных типов могут быть назначены на один и тот же период времени.
Например, "Перемещение + Атака по возможности" означает, что юнит должен двигаться и при обнаружении противника выстрелить без остановки.
Выполняемые Приказы могут быть прерваны на новом ходу игроком, т.е. игрок может удалить остаток приказа и дать другой.
Но есть состояния юнита, которые не могут прерываться.

| Тип      | Приказ               | Описание                                                                      |
|----------|----------------------|-------------------------------------------------------------------------------|
| Движение | Перемещение          | Перемещение в точку назначения                                                |
| Движение | Стоять               | Стоять указанное время, глядя в указанном направлении                         |
| Действие | Атака                | Выполняется атака в указанном направлении                                     |
| Действие | Атака по возможности | Выполняется атака в указанном направлении при наличии противника в зоне атаки |

### 1.3. Юнит
| Компонент      | Параметры                                                                                          |
|----------------|----------------------------------------------------------------------------------------------------|
| Тело           | Позиция, скорость (рандом в диапазоне из конфига), размер, реакция (рандом в диапазоне из конфига) |
| Оружие         | Дальность, конус разброса, урон                                                                    |
| Физический луч | Используется для проверки видимости и выстрелов                                                    |

### 1.4. Сенсорика
| Элемент     | Описание                                            |
|-------------|-----------------------------------------------------|
| Видимость   | Конус, дальность R                                  |
| Обнаружение | Прямая линия без препятствий                        |

 Союзники не требуют обнаружения.

### 1.5. Состояния юнитов
Состояния также разделяются на типы.
Часть состояний может быть отменена новыми приказами, часть - нет.
Состояния также выстроены по timeline.
По сути состояния - это минимальные действия юнита.

| Тип      | Состояние   | Отменяемо | Описание                                                                                                                                                                           |
|----------|-------------|-----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Движение | Перемещение | Да        | Выполняет движение в точку назначения, время выполнения рассчитывается как скорость на расстояние. Движение не останавливается при обнаружении врага и не прерывается атакой       |
| Движение | Стоять      | Да        | Стоит и смотрит в указанном направлении необходимое время                                                                                                                          |
| Действие | Обнаружение | Да        | При появлении в конусе видимости другого юнита делается ожидание на время реакции, а потом лучом проверяется его видимость                                                         |
| Действие | Атака       | Нет       | Выполняется ожидание на время реакции (нажатие на спуск), потом мгновенный выстрел в случайном направлении в пределах конуса разброса оружия, проверка попадания физическим лучом. |

Обнаружение прерывается выходом противника из зоны видимости.
Атака может быть прервана только смертью атакущего юнита.
При Обнаружении также вычисляется расстояние до врага.

Приказ Атака по возможности выполняется как набор из двух состояний действия: Обнаружение и Атака.
При появлении врага в конусе, после текущего выполняемого состояния действия в очередь добавляется Обнаружение.
Также очередь очищается от всех Атак.
После завершения всех Обнаружений в очередь ставится Атака ближайшего из них.
После завершения Атаки, если есть еще враги в зоне поражения, в очередь ставится Атака ближайшего из них.
Выполнение происходит до конца хода или до конца приказа. 

Т.к. выстрел происходит в случайном направлении, то может произойти попадение в своего - FF.
При этом стрельба по своим "осознанно" не производится.

| Элемент | Описание |

| Карта | Плоскость без препятствий |

### 1.7. Интерфейс
В нижней части экрана должен находится timeline с настроенными приказами для выбранного юнита.
Время слева-направо, должны быть отмечены границы ходов.
Длительные приказы могут выходить за пределы одного хода, они продолжат выполнение, если игрок его не удалит.
Также timeline разделен по вертикали на два типа Движение и Действие, для обеспечения параллельности настройки. 
Таким образом, кроме настройки приказа на карте игрок может изменять их длительность.
На timeline также должен быть бегунок для предпросмотра положений своих юнитов в каждый период времени (во время фазы планирования).
При этом коллизии не рассчитываются, т.е. игрок просто должен увидеть наложение юнитов.
На редактирование приказов это никакого влияния не имеет.

Действия на timeline (только при активном юните)

| Действие                           | Описание                                     |
|------------------------------------|----------------------------------------------|
| Выбор приказа                      | Левый клик по плашке приказа                 |
| Создание нового с текущего момента | Левый клик по пустой части timeline          |
| Изменить длительность              | "Зацепить и потянуть" за край плашки приказа |
| Удалить приказ                     | Delete при выделенном                        |
| Масштаб                            | Ctrl + колесико на timeline                  |
| Перемещение "окна видимости"       | Колесико                                     |
| Запуск симуляции                   | Кнопка "Start Turn" или пробел               |

Действия на карте

| Действие         | Описание                                                                   |
|------------------|----------------------------------------------------------------------------|
| Выбор юнита      | Левый клик по юниту                                                        |
| Перемещение      | Правый клик на точку                                                       |
| Стоять           | Создать приказ - Ctrl + левый клик. Правый клик - выбор направления обзора |
| Запуск симуляции | Кнопка "Start Turn" или пробел                                             |

### 1.8. Фаза симуляции
Проигрывается как мультик - происходит одновременное выполнение всеми юнитами данных им приказов.
В этой фазе игрок не может ни на что уже повлиять.
